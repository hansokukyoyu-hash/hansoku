# TENPOS 買取テーマ 導入手順

対象環境：WordPress 7.1.2 / PHP 8.4（`https://tenpos.online/kaitori/`）

## 1. 事前に入れるプラグイン

| プラグイン | 用途 |
|---|---|
| Advanced Custom Fields（無料版で可） | 買取実績・コラム・連載・用語の入力項目（項目定義はテーマ側のコードで自動登録。ACF 側での作成は不要） |
| Contact Form 7 | 査定フォーム・お問い合わせ |

## 2. テーマのインストール

1. 外観 → テーマ → 新規追加 → テーマのアップロード → `tenpos-kaitori.zip` を選択
2. 「有効化」

## 3. 初期設定（管理画面から1クリック）

外観 → **買取サイト初期設定** → 「初期設定を実行」

- 固定ページ（トップ／農機具買取／工具買取／対応エリア／お問い合わせ／プライバシーポリシー／利用規約）を作成し、トップをフロントページに設定
- ジャンル（農機具 `agri`／工具 `tool`／買取・手続き `deal`）を作成
- 「サンプルコンテンツも投入する」にチェックすると、用語集23語・連載2本（記事9本、未来日付は予約投稿）・FAQ 8件・買取実績 8件を投入
- 既にあるものは作らないので、何度実行しても重複しません

続けて **設定 → パーマリンク → 「投稿名」** を選んで保存してください。

## 4. フォーム（Contact Form 7）

1. お問い合わせ → 新規追加 で 2 つ（必要なら 3 つ）フォームを作成
   - 農機具査定：`docs/cf7-agri.txt` の内容を「フォーム」タブに貼り付け
   - 工具査定：`docs/cf7-tool.txt`
   - 共通お問い合わせ：どちらかを流用
2. 「メール」タブは `docs/cf7-mail.txt` を参考に設定（写真添付は `[your-photo]`）
3. 外観 → カスタマイズ → **買取サイト設定** にフォーム ID を入力
   （ショートコード `[contact-form-7 id="xxxx"]` の xxxx）

フォーム未設定の間は、電話番号への導線が表示されます（管理者にだけ設定案内が出ます）。

> ひな形内のプライバシーポリシーへのリンクは `/kaitori/privacy-policy/` 固定です。URL が異なる場合は書き換えてください。

## 5. 買取サイト設定（外観 → カスタマイズ）

電話番号・受付時間・運営会社表記・古物商許可番号・CF7 フォームID。
ロゴを差し替える場合は「サイト基本情報 → ロゴ」（未設定時はテーマ同梱の TENPOS / Dr.テンポス ロゴ）。

## 6. URL 構成

| URL | 内容 | テンプレート |
|---|---|---|
| `/` | トップ（ハブ） | `front-page.php` |
| `/agricultural-equipment/` | 農機具買取 LP | `page-agricultural-equipment.php` |
| `/tool/` | 工具買取 LP | `page-tool.php` |
| `/results/` | 買取実績（全体） | `archive-result.php` |
| `/agricultural-equipment/results/` ・ `/tool/results/` | ジャンル別実績 | 同上 |
| `/results/{slug}/` | 実績詳細 | `single-result.php` |
| `/column/` | コラム一覧（連載＋新着） | `archive-column.php` |
| `/column/series/{slug}/` | 連載トップ | `taxonomy-series.php` |
| `/column/{slug}/` | 記事 | `single-column.php` |
| `/glossary/` | 用語集（`/glossary/{slug}/` は一覧の該当位置へ転送） | `archive-glossary.php` |
| `/faq/` | よくある質問 | `archive-faq.php` |
| `/area/` ・ `/contact/` ほか | 固定ページ | `page.php` |

## 7. 日々の更新

### 買取実績（管理画面「買取実績」）
タイトル・アイキャッチ画像・ジャンル・メーカー／型式／年式／状態／地域／価格。
LP・トップの「最新の買取実績」に自動で表示されます。

### コラム・連載（管理画面「コラム」「コラム → 連載」）
- 連載を作る：コラム → 連載 で名前・**全何回**・ジャンル・リード文・更新ペースを入力
- 記事を書く：右側で「連載」を選び、**連載の回数** を入力
- **公開日を未来にして「予約投稿」すると、路線図や「次回」に公開予定日が自動表示**されます
- 本文は **見出し（H2）の直後の段落が「結論の要約」枠**で表示されます（結論先行の書き方）
- H2 から目次・画面下メニューの目次が自動生成。4つ以上の H2 があると途中に査定 CTA が自動挿入
- 専門用語は `[term slug="meiban"]` または `[term slug="meiban"]表示名[/term]` で、用語集の解説がポップアップします
- 「この記事の結論」「結論のポイント（1行1つ）」「読了目安」を入力すると冒頭に表示

### 用語集（管理画面「用語集」）
タイトル＝用語、本文＝解説（1〜3文）、**よみ（ひらがな・必須）**、ジャンル、関連用語、詳しく読むリンク。
よみ で五十音の行に自動で振り分けられます。

### FAQ（管理画面「よくある質問」）
タイトル＝質問、本文＝回答、ジャンル（農機具／工具／買取・手続き）。並び順は「順序」の数値。
各 LP と `/faq/` に表示され、FAQPage 構造化データも自動出力されます。

## 8. 構造化データ（自動）

- トップ：Organization
- LP・FAQ：FAQPage
- 実績詳細：Product + Offer
- 記事：Article（連載は CreativeWorkSeries）+ BreadcrumbList
- 用語集：DefinedTermSet

## 9. 表示速度まわり

- CSS 1 本・JS 1 本（依存ライブラリなし、`defer`）
- 絵文字・oEmbed 等の不要出力を削除、ブロック用 CSS は本文を使うページのみ
- CF7 の CSS は読み込まず（テーマ側でスタイル）、JS もフォームのあるページだけ
- 画像は WordPress 標準の `loading="lazy"`／`srcset` を利用。WebP/AVIF でアップロードしてください
