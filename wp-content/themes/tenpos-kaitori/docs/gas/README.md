# スプレッドシート自動追記の設定手順

査定フォーム（農機具・工具）と総合問い合わせフォームの送信内容を、Google スプレッドシートに1件1行で自動追記します。

**仕組み（テーマ 1.5.0〜）**：スプレッドシートの Apps Script が **5 分ごとにサイトへ取りに行き**、シートに追記します。
サイトから Google へは送らないので、ウェブアプリのデプロイは不要です。Google Workspace の「組織内のみ」設定のままで動きます。
- 送信から反映まで最大 5 分ほどかかります
- 問い合わせ自体は、反映の成否にかかわらず Flamingo とメールに残ります
- 追記できたものは、サイト側の一時保管から削除されます

## 1. スプレッドシートを用意する
1. 会社の Google アカウントでスプレッドシートを作成（例：「買取サイト 問い合わせ一覧」）
2. **共有は、対応する担当者だけに限定**してください（氏名・電話番号などの個人情報が入ります）

## 2. Apps Script を設定する
1. スプレッドシートのメニュー「拡張機能 → Apps Script」
2. エディタの中身をすべて消して、`Code.gs` の内容をすべて貼り付け → 保存（💾）
3. 上部の関数選択で **`setup`** を選び「実行」
   - 権限の確認が出るので「許可」（「このアプリは Google で確認されていません」と出たら「詳細 → （プロジェクト名）に移動」）
     - 「外部サービスへの接続」「スクリプトの実行（トリガー）」の権限が含まれます（サイトへ取りに行くため）
   - 実行ログに **トークン** が表示されます → メモ（他人に見せない）
   - 「問い合わせ」シートと見出し行、5 分ごとのトリガー（左メニューの ⏰「トリガー」に `pull` が1件）ができます

## 3. WordPress に設定する
外観 → カスタマイズ → **スプレッドシート連携**
- 「スプレッドシートへの自動追記を有効にする」にチェック
- トークン：手順 2-3 の値
- 「公開」

## 4. 確認する
1. ログアウト状態（シークレットウィンドウ等）でテスト送信
2. Apps Script で関数 **`pull`** を選んで「実行」（5 分待っても同じ）→ スプレッドシートに1行追加されれば完了
3. カスタマイザーの「スプレッドシート連携」に「最終取得」の日時が表示されます

## 1.4.x（サイトから送る方式）から切り替える場合
1. Apps Script のコードを新しい `Code.gs` に丸ごと置き換えて保存
2. `setup` を実行（トークンは前と同じ値のまま。新しい権限の許可が求められます）
3. 「デプロイ → デプロイを管理」で、前に作ったウェブアプリのデプロイを **アーカイブ**（もう使いません）
4. WordPress 側はテーマ 1.5.0 に置き換えるだけ（トークンは入力済みのものがそのまま使えます）

## 記録される列
受信日時／フォーム（農機具査定・工具査定・総合問い合わせ）／お名前／電話番号／メールアドレス／都道府県／種類・ご相談内容／メーカー・型番／お問い合わせ内容／写真（「あり（メール添付）」のみ。画像は送らない）／送信ページ／受付ID／対応状況／担当者／メモ

- 「対応状況」「担当者」「メモ」は社内用の空欄です。自由に記入してください
- 列の順番・見出しは変えないでください（Apps Script が列の位置で書き込みます）。列を足す場合は右端に追加
- シート名「問い合わせ」も変えないでください

## 運用上の注意
- 取得に失敗すると、Apps Script からスクリプトの所有者にエラー通知メールが届きます（Google の既定では1日1回まとめて）
- 30 分以上反映されない問い合わせがあると、WordPress の管理画面に警告が出ます
- トークンが漏れた疑いがあるときは、関数 `resetToken` を実行 → 新しいトークンを WordPress 側に入力
- Apps Script の所有者のアカウントが無効になると止まります（担当交代時は、新しい担当者がコピーを作って `setup` し直す）
- 一時停止したいときは、カスタマイザーのチェックを外す（停止中の送信は保管されず、シートにも載りません。Flamingo には残ります）
