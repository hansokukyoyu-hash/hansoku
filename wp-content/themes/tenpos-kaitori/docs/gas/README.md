# スプレッドシート自動追記の設定手順

査定フォーム（農機具・工具）と総合問い合わせフォームの送信内容を、Google スプレッドシートに1件1行で自動追記します。
送信に失敗しても、問い合わせ自体は Flamingo とメールに残ります（管理画面に失敗の通知が出ます）。

## 1. スプレッドシートを作る
1. 会社で管理している Google アカウントで、新しいスプレッドシートを作成（例：「買取サイト 問い合わせ一覧」）
2. **共有は、対応する担当者だけに限定**してください（氏名・電話番号などの個人情報が入ります）

## 2. Apps Script を設定する
1. スプレッドシートのメニュー「拡張機能 → Apps Script」
2. 最初からある `function myFunction() {}` を消して、`Code.gs` の内容をすべて貼り付け → 保存（💾）
3. 上部の関数選択で **`setup`** を選び「実行」
   - 初回は権限の確認が出るので「許可」（「このアプリは Google で確認されていません」と出たら「詳細 → （プロジェクト名）に移動」）
   - 実行ログに **トークン** が表示されます → メモ（他人に見せない）
   - スプレッドシートに「問い合わせ」シートと見出し行ができます
4. 右上「デプロイ → 新しいデプロイ」
   - 種類の選択（⚙）→ **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（サイトのサーバーから送るため。トークンが一致しない送信は記録されません）
   - 「デプロイ」→ 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー
   - 会社の Google Workspace アカウントでは `https://script.google.com/a/macros/<ドメイン>/s/…/exec` と表示されることがあります（そのまま使えます）。ただしアクセスが「組織内のユーザー」だとサーバーからの送信は失敗します。必ず **全員** を選んでください（選べない場合は Workspace 管理者の設定が必要）

## 3. WordPress に設定する
外観 → カスタマイズ → **スプレッドシート連携**
- 「スプレッドシートへの自動追記を有効にする」にチェック
- Apps Script ウェブアプリの URL：手順 2-4 の URL
- トークン：手順 2-3 の値
- 「公開」
- 公開時に「何かうまくいかなかったようです」と出る場合：サーバーの WAF が URL を含む送信を止めている可能性があります。URL の `/s/` と `/exec` の間の **デプロイ ID（AKfycb…）だけ** を入力して公開してください（テーマ 1.4.1 以降。保存時に URL に組み立てます）。または WAF を一時的にオフにして公開し、終わったら戻す

## 4. 確認する
ログアウト状態（シークレットウィンドウ等）でテスト送信 → スプレッドシートに1行追加されれば完了。
カスタマイザーの「スプレッドシート連携」に最終成功日時が表示されます。

## 記録される列
受信日時／フォーム（農機具査定・工具査定・総合問い合わせ）／お名前／電話番号／メールアドレス／都道府県／種類・ご相談内容／メーカー・型番／お問い合わせ内容／写真（「あり（メール添付）」のみ。画像は送らない）／送信ページ／受付ID／対応状況／担当者／メモ

- 「対応状況」「担当者」「メモ」は社内用の空欄です。自由に記入してください
- 列の順番・見出しは変えないでください（Apps Script が見出しの位置で書き込みます）。列を足す場合は右端に追加

## 運用上の注意
- Apps Script のコードを修正したら「デプロイ → デプロイを管理 → 編集 → バージョン：新バージョン → デプロイ」（URL は変わりません）
- トークンが漏れた疑いがあるときは、関数 `resetToken` を実行 → 新しいトークンを WordPress 側に入力
- 送信失敗が続く場合は、WordPress 管理画面の通知と、カスタマイザーの「最終エラー」を確認
