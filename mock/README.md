# 農機具・工具買取サイト モック

企画書（詳細要件定義書）をもとにした静的 HTML モック。WordPress オリジナルテーマ化の前段。

| ページ | パス | トーン |
|---|---|---|
| トップ（軽量ハブ） | `index.html` | 白・スプリットナビ |
| 農機具買取 LP | `agricultural-equipment/index.html` | 緑・茶・白 |
| 工具買取 LP | `tool/index.html` | 黒・黄・赤 |
| コラム一覧 | `column/index.html` | 連載シリーズ＋新着記事（カテゴリ絞り込み） |
| 連載トップ | `column/rinou/index.html` | 「離農・農機具整理ガイド」全5回 |
| 連載記事 | `column/rinou/01.html`, `02.html` | 第1回・第2回（第3回以降は公開予定） |
| 用語集 | `glossary/index.html` | 23語・五十音タブ・検索・カテゴリ絞り込み |

共通: `assets/css/style.css`（`body.theme-*` でトーン切替）／`assets/js/main.js`（依存なし）

## 確認方法
```
cd mock && python3 -m http.server 8000
# http://localhost:8000/ （file:// で直接開いても動作）
```

## Floating Dock（スマホのメニュー＋追従CV）
- ヘッダーにハンバーガーを置かず、親指の届く画面下部のカプセルに「電話／メニュー／WEB査定（フォーム）」を集約
- 中央オーブの外周リング＝ページ読了進捗
- カプセル上のチップ＝今読んでいるセクション名（Dynamic Island 風に切替アニメ）
- 下スクロールでカプセルがコンパクト化、上スクロールで復帰
- オーブをタップ → オーブ中心から円形に広がる全画面 INDEX。各セクションに「読んだ／現在地」を表示し、もう一方の LP への切替カードも配置

## コラム（連載）
- 連載の進み具合を「路線図」で表示（公開中＝実線、公開予定＝点線、既読＝塗りつぶし）
- 記事上部に「EP.01 / 05」と路線図、記事末に前回／次回カード（未公開回は公開予定日を表示）
- 既読はこの端末のブラウザに保存し、連載トップの「続きから読む」に反映
- 本文の点線の用語をタップすると用語集の解説がポップアップ（用語集ページへリンク）
- 記事の Dock：チップ＝今読んでいる見出し、リング＝読了率、メニュー＝記事の目次
- 構造化データ：Article（CreativeWorkSeries）＋ BreadcrumbList

## 用語集
- 五十音タブ（現在の行に追従）、ひらがな・カタカナどちらでも検索可、カテゴリ（農機具／工具／買取・手続き）で絞り込み
- 各用語に「関連用語」と、LP・コラムへの導線
- 構造化データ：DefinedTermSet

## CTA 方針
