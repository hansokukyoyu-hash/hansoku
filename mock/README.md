# 農機具・工具買取サイト モック

企画書（詳細要件定義書）をもとにした静的 HTML モック。WordPress オリジナルテーマ化の前段。

| ページ | パス | トーン |
|---|---|---|
| トップ（軽量ハブ） | `index.html` | 白・スプリットナビ |
| 農機具買取 LP | `agricultural-equipment/index.html` | 緑・茶・白 |
| 工具買取 LP | `tool/index.html` | 黒・黄・赤 |

共通: `assets/css/style.css`（`body.theme-*` でトーン切替）／`assets/js/main.js`（依存なし）

## 確認方法
```
cd mock && python3 -m http.server 8000
# http://localhost:8000/ （file:// で直接開いても動作）
```

## Floating Dock（スマホのメニュー＋追従CV）
- ヘッダーにハンバーガーを置かず、親指の届く画面下部のカプセルに「電話／メニュー／WEB査定（フォーム）」を集約
- 中央オーブの外周リング＝ページ読了進捗
- カプセル上のチップ＝今読んでいるセクション名（Dynamic Island 風に切替アニメ）
- 下スクロールでカプセルがコンパクト化、上スクロールで復帰
- オーブをタップ → オーブ中心から円形に広がる全画面 INDEX。各セクションに「読んだ／現在地」を表示し、もう一方の LP への切替カードも配置

## CTA 方針
主 CTA はすべて **WEB査定フォーム**（LINE は使用しない）。補助として電話。
